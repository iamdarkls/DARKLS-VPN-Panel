Твои маршруты

Домен включает поддомены. Общие адреса CDN могут использоваться несколькими сервисами. Для новых маршрутов устройство должно использовать DNS роутера; защищённый DNS браузера может обходить отбор. Выключенные группы не добавляют новые адреса в VPN, но ранее определённые IP могут сохраняться до 24 часов. Доменные правила для мессенджеров не гарантируют проксирование звонков по прямым IP.

Для каких устройств использовать VPN

Выбранные сайты будут идти через VPN только с учётом этого режима.

Выбор сохраняется по MAC-адресу. IP обновляются каждые 15 секунд. Уже открытые соединения могут сохранять прежний маршрут — перезапусти приложение для проверки. Если устройство сменит приватный MAC, выбери его заново. Новые устройства при режиме «Только выбранные» используют обычное подключение.

Ответ сервиса через VPN

Проверка с роутера через SOCKS Xray: DNS и HTTPS. Не проверяет вход в аккаунт, отправку сообщений, QUIC или маршрут браузера. Один сбой не перезапускает VPN.

Обновления с GitHub
Источник: iamdarkls/DARKLS-VPN-Panel. Проверяем раз в сутки; установка только по кнопке. Подпись Ed25519 подтверждает автора пакета. Xray обновляется отдельно.
Обновить панель
Выбери компактный ZIP-пакет панели. Проверим состав, архитектуру и SHA-256 файлов. Пароль и списки сохранятся; при ошибке установщик попробует вернуть предыдущую версию.
Загружай пакеты из доверенного источника: SHA-256 проверяет целостность, а не автора. Во время установки панель кратко перезапустится, затем потребуется повторный вход.
