Старые инструкции по ручной установке промежуточных версий заменены актуальным порядком обновления через панель. Существующие настройки и пароль сохраняются.

## Команды администратора

Выполняются в **SSH роутера**, не в PowerShell Windows:

```sh
/jffs/xray/panel/darkls-panel --version
/jffs/xray/xray version
/jffs/xray/panel/darkls-panel --check-router
/jffs/xray/panel/darkls-panel --check-vpn
/jffs/xray/panel/darkls-panel --check-components
```

`--recover-components` восстанавливает неисправные компоненты. `--rollback-xray` возвращает проверенную предыдущую копию ядра с USB; соединения переподключатся. Для обычного управления используйте веб-панель.

Не публикуйте `config-vpn.json`, содержимое `profiles/`, `auth.json` или VPN-ссылки. Для обращения за помощью используйте отчёт из панели и проверьте его перед отправкой.

## Диагностика обрывов под нагрузкой

Монитор подтверждает отдельный сбой DNS через Xray двумя повторными запросами и свежей HTTPS-проверкой перед перезапуском ядра. Сбой запроса включает внешний резолвер и транспорт: он не доказывает зависание локального входа. Перед восстановлением сохраняется последний снимок `/tmp/darkls-last-recovery.json`; он заменяется следующей попыткой и исчезает после перезагрузки. Снимок включён в отчёт панели. При структурном отказе снимок может содержать только частичные проверки (`traffic_checked=false`). Тайм-ауты HTTPS: TLS 8 секунд, запрос 12 секунд; DNS — 5 секунд отдельно для каждого входа.

## Режим восстановления

Если откат незавершённой операции не удался (например, отключена USB с копией ядра), панель открывается для диагностики и блокирует изменение настроек. Подключи исходную флешку и нажми «Повторить восстановление» в «Контроль связи → Восстановление», подтвердив пароль. Пока журнал остаётся, обновления, очистка и переключения недоступны. Отсутствующая или повреждённая копия не удаляется автоматически. При ошибке восстановления проверь журнал и скачай отчёт; не удаляй журналы отката вручную.
