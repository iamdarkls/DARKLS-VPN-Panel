## Границы правил

Для FaceTime указаны домены, часть которых используется другими функциями Apple. Apple описывает дополнительные сетевые требования: https://support.apple.com/en-ie/102036 и https://support.apple.com/en-us/101555. Одних доменов может не хватить для звонков по прямым IP. Аналогично звонки других мессенджеров, игровые соединения и серверы замера скорости могут потребовать отдельных правил. Группы RuTracker/RuTor предназначены для сайтов, не для всего BitTorrent-трафика.

Roblox исключён из каталога: Интерфакс сообщил о снятии ограничений 10.06.2026: https://www.interfax.ru/digital/1095228 . Сервисы, самостоятельно прекратившие обслуживание РФ (без подтверждения блокировки РКН), в эту подборку не включались.

Официальная ручная проверка конкретного адреса: https://blocklist.rkn.gov.ru/ . Включение группы не даёт гарантий доступности сервиса или обхода его собственных региональных/платёжных ограничений.
