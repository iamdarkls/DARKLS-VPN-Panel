# Изменения

## 1.4.3

- Каталог расширен сервисами с собственными региональными ограничениями: TikTok, Spotify, Netflix, Claude / Anthropic, Notion, Miro, Canva, Adobe / Creative Cloud / Firefly, Autodesk и Wrike.
- Добавлен раздел «Работа и дизайн». В карточках новых сервисов показаны пояснения об ограничениях аккаунта, лицензии, оплаты и региона: VPN не гарантирует восстановление всех функций.
- В разделе 18+ добавлены ещё 20 отдельных групп; всего теперь 28. Основные домены и часть CDN сверены по открытым спискам доменов.
- Все новые группы выключены. Существующие имена, домены, выбор VPN и QUIC сохраняются; повторное обновление не создаёт дубликаты. Обновлены источники каталога и браузерные проверки.

## 1.4.2

- Рефакторинг: валидация настроек, файловые операции, применение с откатом и фоновые задачи вынесены в отдельные модули. Добавлены комментарии к блокировкам, журналам восстановления и ограничениям памяти; JavaScript приведён к читаемому виду.
- Фоновые задачи используют общий планировщик без накопления пропущенных запусков. Таймеры групп и обновление устройств объединены; неизменившийся список устройств больше не вызывает сканирование процессов.
- Проверки сервисов распределены по времени, по одной пробе за цикл. Обслуживание логов выполняется примерно раз в минуту вместо отдельного запуска каждые 15 секунд.
- Метаданные Xray разбираются потоком. В локальном тесте суммарные выделения памяти при разборе списка уменьшились примерно на 67%; это не измерение общего потребления RAM роутера.
- Исправлено перезаписывание редактируемых настроек фоновым обновлением страницы. Одновременные запросы состояния Xray объединяются; загрузка ZIP и обновление панели через GitHub используют общий механизм ожидания.
- После сетевой ошибки проверка обновлений повторяется через час. Исправлена оценка свежести результатов после перевода часов; статус VPN учитывает основной процесс Xray и ограничивает время ожидания системных команд.
- Проверены Go race/vet, отмена фоновых задач, выбор релизов, браузерные сценарии и обновление/откат с имитацией команд роутера. Настройки и пароль сохраняются; фактическая нагрузка на ASUS проверяется после установки.

## 1.4.1

- Xray: поиск стабильных выпусков и пререлизов вместо stable-only API. Среди 30 последних опубликованных выпусков выбирается самая новая числовая версия с ARM64-архивом; черновики исключены.
- В панели показан тип найденного выпуска. Автоустановка, если включена, также учитывает пререлизы; по умолчанию она выключена.
- Сохранены проверка официального источника и SHA-256, запрет понижения версии, USB-копия и откат, блокировка автоматических повторов неудачной версии.
- Описание изменений публикуется непосредственно в GitHub Releases. Ссылки на отдельный чейнджлог убраны из README.

## 1.4.0

- Обновления Xray из официального стабильного XTLS/Xray-core: суточная проверка, примечания, установка по кнопке и отдельное расписание автоустановки в МСК. Автоустановка изначально выключена.
- ARM64, официальный SHA-256, потоковая загрузка/распаковка на USB, проверка текущего конфига, постоянная копия прежнего ядра и журнал отката. Во время успешной замены перезапускается только Xray; после запуска проверяются DNS, правила и HTTPS.
- Неудачные версии блокируются для автоповтора; ручной повтор требует явного выбора. Автоматическое понижение запрещено, за ночь — не больше одной попытки.
- Кнопка возврата предыдущего ядра с USB; отсутствие/повреждение копии проверяется до изменения рабочего ядра и записи нового журнала.
- Автоочистка известных лишних файлов старше семи дней, раз в шесть часов. Последние копии, действующий откат, активные файлы и неизвестные пути защищены. Есть переключатель и ручной запуск.
- Исправлен путь к состоянию в CLI --check-router: глубокая проверка больше не получает пустой корневой каталог. Создание объекта сервера унифицировано.
- Общий неизменяемый CA pool, таблица API создаётся один раз, убрано дублирование потоковой загрузки и запуска установщика. Метрики Xray учитывают основной процесс, а не временный тестовый.
- README и техническое руководство переписаны; восстановлен воспроизводимый микротест RSS. Общий RSS по нему остаётся около 13 МиБ, существенное снижение не заявляется.
- Добавлены тесты источника/версий/SHA-256, расписания, безопасной распаковки, несовместимого конфига, очистки и защиты API; браузерный сценарий новых настроек.

Проверки локальные и CI. Установка нового ядра на конкретной прошивке и длительная стабильность транспорта требуют проверки на реальном ASUS. Обновление панели само по себе не меняет ядро.

## 1.3.0

- Отчёт о сбое в JSON: версии, ресурсы, правила, DNS и последние ошибки. Конфиг не экспортируется; ключи и адрес VPN-сервера удаляются, IPv4/MAC заменяются метками.
- Диагностика известных зависимостей семи сервисов: DNS, настройка маршрута, IP-набор и HTTPS. Cloudflare и ответы CDN не считаются отказом общего туннеля.
- QUIC для каждой группы, пробный режим на 5 минут с возвратом прежнего выбора, ручная оценка TCP/QUIC. YouTube сохраняет запрет по умолчанию.
- Предпросмотр доменов, групп и области устройств перед сохранением; таймер включения любой группы на 1–1440 минут.
- Ограниченная история сервисов в RAM, длительность предыдущего состояния и состояние общего туннеля на момент проверки. Периодичность настраивается; по умолчанию 5 минут.
- Раздельное восстановление DNS helper, правил и Xray. При частичном отказе больше не выполняется безусловный полный vpn.sh start. Первая неудачная HTTPS-проверка запускает сбор состояния компонентов.
- Подготовка правил в отдельной цепочке перед подключением; DNS-кеш и активные соединения сохраняются. Старые IP удалённых доменов могут действовать до истечения кеша.
- Безопасный список предыдущей панели, снимков настроек, известных установочных архивов и прежних ядер на USB; удаление выбранного с паролем и объяснением последствий.
- Изолированное сравнение трёх XMUX-вариантов XHTTP и отдельное применение с проверкой/откатом; требуется 96 МиБ доступной RAM. Путь, Reality и адрес сервера не заменяются настройкой XMUX.
- Ограниченный тест задержки под HTTP-нагрузкой: прямой канал/VPN, до 8 МиБ и 8 секунд нагрузки. QoS автоматически не меняется; короткая выборка помечается недостаточной.
- Второй outbound (VLESS-ссылка или JSON): изолированная HTTPS-проверка перед сохранением и переключением, журнал отката. Автопереключение выключено до настройки; автоматического возврата на основной нет.
- Состав пакета сохранён для обновления с 1.2.0; Xray 26.10.10, пароль, группы, устройства и USB-автозапуск сохраняются.

Проверено локально: Go race/vet, имитация отказа подготовки правил, журнал переключения, миграции/таймеры, браузер desktop/mobile, сценарии установщика и OTA с заглушками команд роутера. Реальная скорость, длительная стабильность XHTTP, QUIC приложений и второй сервер требуют замеров на ASUS.
