# DARKLS VPN Panel

Локальная панель для управления Xray на **ASUS TUF-BE6500**: выбирай сайты и устройства для VPN, переключай серверы, проверяй связь и устанавливай обновления.

[Скачать выпуск](https://github.com/iamdarkls/DARKLS-VPN-Panel/releases/latest) · [Открыть панель](http://192.168.50.1:8088) · [Руководство](docs/USER_GUIDE.md) · [Разработка](docs/DEVELOPMENT.md)

Панель рассчитана на **уже настроенный VPN**. Она не содержит подписку, персональные ключи и конфигурацию сервера. Работает в домашней сети без облачного аккаунта и GitHub-токена на роутере.

## Разделы панели

| Раздел | Для чего |
| --- | --- |
| **Сайты и сервисы** | Группы доменов, категории, поиск, QUIC по группам, временное включение и предпросмотр изменений |
| **Устройства** | VPN для всей сети, выбранных устройств или всех, кроме исключений; привязка к MAC |
| **VPN-серверы** | Текущее подключение, до 20 сохранённых серверов, VLESS/JSON/ручной ввод; отдельная вкладка резервного канала |
| **Диагностика** | Связь, DNS, HTTPS, зависимости сервисов, прогноз маршрута устройства и отчёт о сбое |
| **Контроль связи** | История доступности, раздельное восстановление компонентов и настройки автоконтроля |
| **Настройка связи** | Пробный QUIC/TCP, сравнение параметров XHTTP и задержка под нагрузкой |
| **Обновления** | Панель с GitHub, ядро Xray и ручная установка ZIP — на отдельных вкладках |
| **Копии и файлы** | Снимки настроек, импорт/экспорт, известные установочные файлы и недельная очистка |
| **Ресурсы роутера** | CPU, доступная RAM, RSS процессов, место в JFFS и наличие USB |
| **Журнал** | События, автоконтроль, работа панели и обновления |
| **Пароль панели** | Смена пароля с завершением прежних сеансов |

Меню сгруппировано в «Маршруты», «Связь» и «Система». Вкладки сохраняют незавершённые формы. Уведомления появляются снизу справа; светлая и тёмная темы работают без внешних шрифтов и скриптов. Интерфейс передаётся с gzip, неизменившиеся JS/CSS перепроверяются по ETag.

## Обновить панель

1. Открой **Обновления → Панель · GitHub → Проверить обновления**.
2. Нажми **«Установить проверенный выпуск»** и введи текущий пароль.
3. Дождись завершения, войди повторно и обнови страницу через **Ctrl+F5**.

В старых версиях до 1.7.0 эта функция находится в «Настройках». Пароль, группы, устройства и реквизиты VPN сохраняются. Обновление панели не меняет версию Xray.

Для ручной установки скачай `DARKLS-VPN-Panel-v<версия>.zip` из [Releases](https://github.com/iamdarkls/DARKLS-VPN-Panel/releases) и открой **Обновления → Установка из ZIP**. Архив Xray для этого поля не подходит. Обновление с GitHub проверяет Ed25519-подпись; ручной ZIP проверяется по составу и SHA-256 и требует доверенного источника.

## Обновить Xray

Открой **Обновления → Ядро Xray**. Поддерживаются официальные стабильные выпуски и пререлизы [XTLS/Xray-core](https://github.com/XTLS/Xray-core/releases).

Автопроверка включена, автоустановка изначально выключена. Для автоустановки задаются час **МСК** и отсрочка после публикации: по умолчанию 3 суток, диапазон 0–30. Ручная установка доступна сразу. Перед заменой сохраняется прежнее ядро на USB, проверяются конфиг и туннель; при ошибке выполняется откат. VPN-соединения при замене ядра переподключатся.

## Требования

- ASUS **TUF-BE6500**, Linux **aarch64**, штатная прошивка с SSH.
- Существующая установка Xray в `/jffs/xray`: `config-vpn.json`, `vpn.sh`, `watch.sh`, dnsmasq с ipset и iptables с TPROXY.
- Домашняя сеть `192.168.50.0/24`, интерфейс `br0`; панель `192.168.50.1:8088`.
- Подключённая флешка **WINDOWS_10** для текущего USB-автозапуска и постоянной копии ядра для отката.

Панель и Xray работают из JFFS. Схема для других моделей, подсетей и загрузчиков требует адаптации. Доступ по HTTP предназначен для доверенной домашней сети.

## Что учитывать

- Выбранные домены маршрутизируются через DNS роутера и IP-наборы. Защищённый DNS браузера может обходить этот механизм; общие IP CDN могут затрагивать несколько сервисов.
- Уже открытые соединения могут сохранять прежний маршрут. Для проверки изменений перезапусти приложение; ранее найденные IP могут оставаться в кеше до 24 часов.
- Отказ одного сайта или проверка Cloudflare не вызывают полный перезапуск VPN. Диагностика с роутера не подтверждает вход в аккаунт или работу конкретного браузера.
- Очистка удаляет только известные лишние файлы старше недели и сохраняет последние копии для отката. Журналы ограничены размером в RAM и сбрасываются после перезагрузки роутера.

## Структура репозитория

| Папка | Содержимое |
| --- | --- |
| `cmd/darkls-panel/` | Точка запуска приложения |
| `internal/panel/` | Сервер, компоненты VPN и Go-тесты рядом с кодом |
| `web/` | HTML, стили и JavaScript: `core`, `components`, `features` |
| `assets/` | Публичный ключ подписи и корневые сертификаты |
| `tests/` | Браузерные сценарии и проверки установки/обновления |
| `tools/` | Сборка, подготовка описания выпуска и подпись |
| `release/`, `router/` | Скрипты обновления и обслуживания роутера |
| `docs/`, `bench/` | Руководства и измерения ресурсов |

Интерфейс использует классы с собственным состоянием; сервер Go — компоненты, методы и композицию. Подробности описаны в [архитектуре](docs/ARCHITECTURE.md).
